# TT Players PWA

Reusable PWA runtime and Vite configuration used by TT Players apps.

Published package: `@wudong/tt-players-pwa` on GitHub Packages.

## What it owns

- install prompt capture for browsers that support `beforeinstallprompt`
- iOS/iPadOS home-screen guidance state, including modern iPad desktop-class user agents
- install-prompt dismissal cooldown
- service-worker update detection and activation
- optional persistent-storage request before an update
- an app lifecycle hook (`onBeforeUpdate`) so each app can protect its own local data
- shared `vite-plugin-pwa` defaults for prompt-based updates, common assets, and Workbox precaching

It intentionally does **not** own app-specific UI. Consumers render their own install/update sheets using `usePWAInstallContext()`.

## Install from GitHub Packages

Configure the `@wudong` scope to use GitHub Packages. For local development, use a GitHub token with package read access through your normal npm authentication setup rather than committing a token to the repository.

```ini
@wudong:registry=https://npm.pkg.github.com
```

Then install the package and its runtime peers:

```sh
pnpm add @wudong/tt-players-pwa react vite workbox-window
```

`workbox-window` must be present in the consuming Vite app because the React virtual registration module generated by `vite-plugin-pwa` resolves it from the consumer dependency graph.

## Vite setup

```ts
import { defineConfig } from 'vite';
import { createPWAPlugin } from '@wudong/tt-players-pwa/vite';

export default defineConfig({
  plugins: [
    createPWAPlugin({
      manifest: {
        name: 'My App',
        short_name: 'MyApp',
        theme_color: '#17382f',
        background_color: '#f1f8f2',
        display: 'standalone',
        icons: [
          { src: '/icon-192.png', sizes: '192x192', type: 'image/png' },
          { src: '/icon-512.png', sizes: '512x512', type: 'image/png' },
        ],
      },
    }),
  ],
});
```

The helper defaults to `registerType: 'prompt'`, includes the standard favicon/apple/mask assets, and precaches JS, CSS, HTML, icons, images, SVG, and web fonts. Any `vite-plugin-pwa` option can still be overridden by the app.

## React runtime

```tsx
import {
  PWAInstallProvider,
  usePWAInstallContext,
} from '@wudong/tt-players-pwa';

function Root({ children }: { children: React.ReactNode }) {
  return (
    <PWAInstallProvider
      onBeforeUpdate={() => {
        // Optional: persist or back up app-specific local state.
      }}
    >
      {children}
    </PWAInstallProvider>
  );
}

function InstallOrUpdateControls() {
  const {
    canInstall,
    canUpdate,
    showInstallSheet,
    showIosSheet,
    triggerInstallPrompt,
    updateApp,
  } = usePWAInstallContext();

  return (
    <>
      {canInstall ? <button onClick={triggerInstallPrompt}>Install</button> : null}
      {canUpdate ? <button onClick={() => void updateApp()}>Update</button> : null}
      {showInstallSheet || showIosSheet ? <div>Render your install UI here.</div> : null}
    </>
  );
}
```

The context also exposes `showUpdateSheet`, `install`, `dismiss`, and `dismissUpdate`. `showInstallSheet` is intentionally platform-neutral: browsers other than Android can expose `beforeinstallprompt`.

## Publishing and validation

This package is built and published by the same GitHub Actions workflow as the TT Players design system. Before publishing, CI:

1. runs the package unit tests,
2. builds the publishable `dist` package,
3. inspects the tarball contents, and
4. installs the real packed tarball into a temporary standalone Vite consumer, type-checks it, and runs a production build.

Bump `packages/pwa/package.json` before changing a version that has already been published.
